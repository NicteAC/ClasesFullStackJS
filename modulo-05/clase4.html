¿Qué es DDL?

DDL (Data Definition Language) describe cómo crear, alterar o eliminar los elementos que componen una base de datos.

Sentencias DDL más comunes

📌 CREATE TABLE

Crea una nueva tabla

CREATE TABLE Empleados ( id_empleado INT PRIMARY KEY, nombre VARCHAR(100), salario DECIMAL(10,2) );

✏️ ALTER TABLE

Modifica la estructura

ALTER TABLE Empleados ADD fecha_ingreso DATE;

🗑️ DROP TABLE

Elimina una tabla

DROP TABLE IF EXISTS Empleados_backup;

🔍 CREATE INDEX

Crea un nuevo índice

CREATE INDEX idx_salario ON Empleados (salario);

Bloque 4

Restricción de nulidad

Especifica si una columna puede tener valores nulos (ausentes) o si debe contener siempre un valor válido.

NOT NULL vs NULL

🔒 NOT NULL

Obligatorio: la columna NO puede estar vacía. Cada registro debe tener un valor válido.

nombre VARCHAR(50) NOT NULL
vs

🕳️ NULL (por defecto)

Opcional: la columna puede estar vacía. Los registros pueden tener o no valor.

telefono VARCHAR(20) -- por defecto acepta NULL

Ejemplo con NOT NULL

CREATE TABLE Empleados ( id INT PRIMARY KEY, nombre VARCHAR(50) NOT NULL, salario DECIMAL(10, 2) );

✅ La columna nombre tiene NOT NULL, todos los registros deben tener nombre.

⚠️ La columna salario puede quedar vacía si aún no se ha asignado.

Ejemplo permitiendo NULL

CREATE TABLE Clientes ( id INT PRIMARY KEY, nombre VARCHAR(50), telefono VARCHAR(20) );

💡 Sin la palabra clave NOT NULL, las columnas aceptan valores nulos por defecto.

Los registros pueden crearse aunque falten nombre o telefono.

</>

AE 4.2 · Bloque 5

Modificar una tabla
con ALTER TABLE

Permite modificar la estructura de una tabla ya existente: agregar, modificar o eliminar columnas.

Agregar una columna

ALTER TABLE empleados ADD fecha_de_nacimiento DATE;

💡 ALTER TABLE + nombre de la tabla, seguido de la acción a realizar.

En este caso: ADD + nombre de la nueva columna + tipo de dato.

Renombrar una columna

ALTER TABLE empleados CHANGE nombre_antiguo_columna nombre_nuevo_columna VARCHAR(50);

💡 CHANGE requiere: nombre antiguo + nombre nuevo + tipo de dato (incluso si no cambia).

Modificar el tipo de dato

ALTER TABLE nombre_de_tabla MODIFY nombre_de_columna nuevo_tipo_de_dato;

💡 MODIFY cambia el tipo o restricciones de una columna existente sin cambiar su nombre.

-- Ejemplo real: cambiar INT a DECIMAL para precios ALTER TABLE Productos MODIFY precio DECIMAL(10, 2);

Modificar restricción de nulidad

Cambiar una columna que permitía NULL a NOT NULL

-- Paso 1: la tabla original permite NULL en email CREATE TABLE clientes ( id INT PRIMARY KEY, nombre VARCHAR(50), email VARCHAR(100) ); -- Paso 2: hacer que email sea obligatorio ALTER TABLE clientes MODIFY COLUMN email VARCHAR(100) NOT NULL;

Agregar / eliminar restricciones

-- Eliminar una restricción existente ALTER TABLE nombre_de_tabla DROP CONSTRAINT nombre_de_restriccion; -- Agregar una nueva restricción ALTER TABLE nombre_de_tabla ADD CONSTRAINT nueva_restriccion ...;

⚠️ Importante: la sintaxis puede variar según el sistema (MySQL, PostgreSQL, SQL Server). Antes de modificar una tabla en producción, siempre hacer backup.

Bloque 6

Eliminar una tabla
con DROP TABLE

Elimina completamente la tabla y todos sus datos de la base de datos.

Sintaxis de DROP TABLE

DROP TABLE nombre_de_tabla;

⚠️ ¡CUIDADO! Esta instrucción elimina la tabla y TODOS sus datos de forma permanente. Úsala con precaución.

-- Versión más segura (no falla si no existe) DROP TABLE IF EXISTS Productos_backup;

Bloque 7

Truncar una tabla
con TRUNCATE

Elimina todos los datos de la tabla, pero mantiene su estructura y definición intactas.

DROP vs TRUNCATE

La diferencia clave

DROPTABLE

❌ Elimina la tabla completa

❌ Elimina la estructura

❌ Elimina los datos

❌ Elimina los índices

Resultado: la tabla ya no existe

vs

TRUNCATETABLE

✅ Mantiene la tabla

✅ Mantiene la estructura

❌ Elimina los datos

✅ Mantiene los índices

Resultado: la tabla existe pero está vacía

Sintaxis de TRUNCATE TABLE

TRUNCATE TABLE productos;

💡 Todos los registros se eliminan, pero la estructura de la tabla permanece intacta.

Es mucho más rápido que DELETE FROM cuando queremos vaciar toda una tabla.
