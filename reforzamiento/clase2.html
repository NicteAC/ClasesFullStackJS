¿Qué es JavaScript?

Lenguaje de programación creado en 1995 por Brendan Eich en solo 10 días. Nació para dar interactividad a las páginas web.

🌐

Vive en el navegador

Chrome, Firefox, Safari, Edge... todos ejecutan JavaScript de forma nativa.

⚡

Interpretado

No necesita compilarse. El navegador lo ejecuta línea por línea.

🔀

Dinámico y flexible

Tipado dinámico. Las variables pueden cambiar de tipo en tiempo de ejecución.

¿Qué PUEDE hacer JavaScript en el navegador?

🎨

Modificar HTML/CSS

Cambiar el contenido y estilo de la página dinámicamente

🖱️

Reaccionar a eventos

Clicks, teclas, movimiento del mouse, formularios

🔄

Comunicarse con servidores

Enviar y recibir datos sin recargar la página

💾

Guardar datos localmente

LocalStorage, cookies, IndexedDB

🎬

Crear animaciones

Transiciones, juegos, gráficos con Canvas

📱

Detectar el dispositivo

Tamaño de pantalla, ubicación, cámara, micrófono

¿Qué NO puede hacer JavaScript en el navegador?

Por seguridad, el navegador limita a JavaScript:

🚫

Acceder al sistema de archivos

No puede leer/escribir archivos del disco duro directamente (excepto con permisos explícitos del usuario)

🔒

Ejecutar programas del sistema

No puede lanzar aplicaciones ni ejecutar comandos del sistema operativo

🌐

Acceder a otros dominios

Same-Origin Policy: no puede leer datos de otros sitios sin permiso (CORS)

💻

Instalar programas

El navegador es una "cárcel dorada" (sandbox) que protege tu computador

¿Qué es una variable?

Un contenedor con un nombre que guarda un valor. Como una caja etiquetada donde ponemos información para usarla después.

let nombre = "Carola"; let edad = 35; let esInstructora = true; console.log(nombre); // "Carola" console.log(edad); // 35

let, const y var

Tres formas de declarar variables

✅ let

Variable que puede cambiar. Es la más usada en la actualidad.

let saldo = 1000; saldo = 1500; // ✓ OK

🔒 const

Constante que NO puede cambiar. Para valores fijos.

const PI = 3.14; PI = 4; // ✗ Error

⚠️ var

Sintaxis antigua. Evítala en código moderno. Solo la verás en tutoriales viejos.

var x = 10; // Funciona pero es // problemática

📛 Cómo nombrar variables

✅ Permitido

  • Letras, números y guion bajo (_)
  • Empezar con letra o _
  • camelCase (recomendado)
  • Distingue mayúsculas y minúsculas
nombreUsuario edad_2 _privado $total

❌ Prohibido

  • Empezar con número
  • Palabras reservadas (let, if, class)
  • Espacios en blanco
  • Símbolos especiales (@, #, %)
1nombre // ✗ nombre usuario // ✗ let // ✗ mi-nombre // ✗

📋 Arrays (arreglos)

Estructura que almacena múltiples valores bajo un mismo nombre, accesibles por su índice.

// Crear un array let colores = ["rojo", "verde", "azul"]; // Los índices empiezan en 0 (¡no en 1!) console.log(colores[0]); // "rojo" console.log(colores[1]); // "verde" console.log(colores[2]); // "azul" // Cantidad de elementos console.log(colores.length); // 3

🛠️ Operaciones con arrays

➕ Agregar

// Al final colores.push("amarillo"); // Al inicio colores.unshift("blanco");

➖ Quitar

// El último colores.pop(); // El primero colores.shift();

🔍 Buscar

// Índice de un valor colores.indexOf("rojo"); // ¿Contiene? colores.includes("rojo");

🔗 Combinar

// Unir arrays [1, 2].concat([3, 4]); // A string colores.join(", ");

🔁 Ciclo while

Se repite MIENTRAS la condición sea verdadera

let contador = 1; while (contador <= 5) { console.log("Vuelta número " + contador); contador++; // ¡MUY IMPORTANTE incrementar! } // Imprime: Vuelta número 1, 2, 3, 4, 5

⚠️ ¡CUIDADO! Si te olvidas del incremento, tienes un bucle infinito y el navegador se congela.

🔂 Ciclo do-while

Se ejecuta al menos una vez, luego verifica

let intentos = 0; do { intentos++; console.log("Intento " + intentos); } while (intentos < 3); // Imprime: Intento 1, Intento 2, Intento 3

💡 Diferencia con while: do-while ejecuta el cuerpo PRIMERO y evalúa DESPUÉS. Ideal para pedirle algo al usuario al menos una vez.

🎯 Ciclo for

El más usado para recorrer arrays

// inicio condición incremento for (let i = 0; i < 5; i++) { console.log("Iteración " + i); } // Recorrer un array let frutas = ["manzana", "pera", "uva"]; for (let i = 0; i < frutas.length; i++) { console.log(frutas[i]); }

🔄 Ciclos anidados

Un ciclo dentro de otro ciclo

// Tabla de multiplicar del 1 al 3 for (let i = 1; i <= 3; i++) { for (let j = 1; j <= 3; j++) { console.log(`${i} x ${j} = ${i * j}`); } } // Salida: 1x1=1, 1x2=2, 1x3=3, 2x1=2, ...

🧩 ¿Qué es una función?

Un bloque de código reutilizable que realiza una tarea específica. Se define una vez y se ejecuta cuantas veces sea necesario.

// Declaración de una función function saludar() { console.log("¡Hola a todos!"); } // Invocación (ejecución) saludar(); // Imprime: "¡Hola a todos!" saludar(); // Puede llamarse muchas veces saludar();

📥 Parámetros y 📤 return

// Función con parámetros y retorno function sumar(a, b) { return a + b; } let resultado = sumar(5, 3); console.log(resultado); // 8 // Función más elaborada function calcularIVA(precio) { const IVA = 0.19; return precio * IVA; } console.log(calcularIVA(10000)); // 1900

🔭 Variables locales vs globales

let nombreGlobal = "Carola"; // Variable GLOBAL function saludar() { let mensajeLocal = "Hola"; // Variable LOCAL console.log(mensajeLocal + " " + nombreGlobal); // ✓ Ambas visibles aquí } saludar(); console.log(nombreGlobal); // ✓ "Carola" console.log(mensajeLocal); // ✗ Error: no existe fuera

⚠️ El problema de las variables globales: se pueden modificar desde cualquier lugar del código, generando bugs difíciles de rastrear. Prefiere siempre variables locales.

🎁 Funciones anidadas

Una función dentro de otra función

function calcularPropina(cuenta) { // Función interna (solo visible aquí adentro) function obtenerPorcentaje() { return 0.10; // 10% de propina } return cuenta * obtenerPorcentaje(); } console.log(calcularPropina(50000)); // 5000

🎁 ¿Qué es un objeto?

Colección de propiedades (datos) y métodos (funciones) relacionados

let persona = { // Propiedades nombre: "Carola", edad: 35, ciudad: "Santiago", // Método (función dentro del objeto) saludar: function() { return "Hola, soy " + this.nombre; } }; // Notación de PUNTO console.log(persona.nombre); // "Carola" console.log(persona.saludar()); // "Hola, soy Carola" // Notación de CORCHETES console.log(persona["nombre"]); // "Carola"

🧮 Objeto Math

Herramientas matemáticas preconstruidas

Propiedades

Math.PI // 3.14159... Math.E // 2.71828...

Métodos comunes

Math.round(4.7); // 5 (redondeo) Math.floor(4.7); // 4 (piso) Math.ceil(4.1); // 5 (techo) Math.abs(-5); // 5 (absoluto) Math.max(1, 5, 3); // 5 Math.min(1, 5, 3); // 1 Math.pow(2, 3); // 8 (potencia) Math.sqrt(16); // 4 (raíz) Math.random(); // 0.xxxx

📝 Objeto String

Métodos para manipular texto

Información

let texto = "Hola Mundo"; texto.length; // 10 texto.toUpperCase(); // "HOLA MUNDO" texto.toLowerCase(); // "hola mundo" texto.charAt(0); // "H" texto.indexOf("Mundo"); // 5 texto.includes("Hola"); // true

Transformación

texto.slice(0, 4); // "Hola" texto.replace("H", "K"); // "Kola Mundo" texto.split(" "); // ["Hola","Mundo"] texto.trim(); // quita espacios texto.concat("!"); // "Hola Mundo!" texto.repeat(2); // "HolaHola..."

String primitivo vs objeto String

// Primitivo (recomendado 99% del tiempo) let nombre1 = "Ana"; // Objeto String (raramente necesario) let nombre2 = new String("Ana"); console.log(typeof nombre1); // "string" console.log(typeof nombre2); // "object" // Ambos tienen los mismos métodos gracias a JavaScript console.log(nombre1.toUpperCase()); // "ANA" console.log(nombre2.toUpperCase()); // "ANA"

💡 Regla: siempre usa la forma primitiva "texto". Es más rápida y sencilla.
